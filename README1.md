# YouTube Trends & Engagement Analytics

## Project objective
Build an end-to-end analytics solution using the YouTube Data API and Microsoft Fabric to understand video popularity and engagement.

## Technologies
- Python
- YouTube Data API v3
- Microsoft Fabric Notebooks
- PySpark
- Fabric Lakehouse
- Delta tables
- SQL
- Power BI

## Architecture
- **Bronze:** Store the original YouTube API responses.
- **Silver:** Clean, transform and deduplicate video data.
- **Gold:** Prepare analytics-ready tables and engagement metrics.

## Data limitations
This project uses publicly available YouTube video data. It does not represent all YouTube viewing activity or reconstruct historical popularity rankings that were not collected at the time.
